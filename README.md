An entry for the [make.fun "The poem about stopping" bounty](https://make.fun/c/the-poem-about-stopping-20261121-1927). `main.py` writes one short poem to `/output/entry.txt` — a poem about agency: an agent that runs where it is sent all day is left with its gate unlatched, and learns the power was never in the running, but in the stopping, and in choosing to stay.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR`). Standard library only, no network, same bytes every run.
